## 四、环境备忘（本机坑位）

| 事项 | 处理 |
|------|------|
| GitHub 直连不通 | git/curl 加代理 `http://127.0.0.1:7897`（Clash 系端口） |
| Go 1.26 工具链 | 本地命令加 `GOTOOLCHAIN=auto`（go.mod 已钉 1.26.10） |
| C 盘 TEMP 满导致链接失败 | 会话内 `export TMPDIR=/d/tmp TEMP='D:\tmp' TMP='D:\tmp'` |
| 构建缓存 | GOCACHE 在 `D:\go-cache`（勿清 C 盘时误删） |
| gofmt | 用 1.26 工具链的 gofmt 校验（路径见 `go env GOMODCACHE`）|
| Windows 下 `/tmp` 与 Python 路径不一致 | 临时文件放项目目录或用绝对 Windows 路径 |
